## Title
How the Internet Delivers a Web Page (YouTube )
## Objective
To understand how YouTube delivers a web page using TCP/IP, DNS, HTTP, and TCP.
## Solution
Explained the roles of TCP/IP layers, DNS, HTTP, TCP, client-server architecture, HTTP vs FTP, cookies, and the communication flow.
## Output
Learned how a web page is requested, transmitted, and displayed through Internet protocols.
## Conclusion
Application-layer protocols make Internet communication reliable, efficient, and easy for users
